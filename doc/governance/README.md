# 治理资料目录

本目录用于统一管理签名、年度收益公开、奖金分配明细与费用简报。

## 子目录说明

- `cla-signatures/`：CLA 签署记录与签署回执（按年归档）
- `revenue-disclosures/`：年度收益公开文件
- `bonus-distributions/`：年度奖金分配方案与执行明细
- `cost-reports/`：年度成本费用明细与简报
- `email-templates/`：法务/CLA 与安全漏洞邮件模板
- `gitlab-gate-setup-checklist.md`：GitLab 门禁配置与验收清单

## 建议命名规范

- 年度文件：`YYYY-summary.md`
- 详细明细：`YYYY-details.md`
- 如果需要月度文件：`YYYY-MM-report.md`
