# CLA 签署登记表（register）

用于集中维护贡献者 CLA 签署记录。  
维护原则：先登记再放行（加入 `.github/cla-signed-users.txt`）。

## 隐私与最小化原则（强制）

为降低个人信息暴露风险，本登记表仅保存最小必要信息，不记录法定姓名与邮箱等敏感个人信息。  
如需完整签署材料，请在私有渠道留存，并通过“证据编号/内部链接”在本表关联。

## 提起审核用户必填内容（强制）

提起 CLA 审核时，申请人必须提供并填写以下字段：

1. 贡献者标识（GitHub/GitLab 用户名）
2. CLA 版本（建议填写 `CLA.md` 的“最后更新”日期）
3. 签署日期时间（UTC+8）
4. 签署方式（邮件 / PR 评论 / 线下扫描件等）
5. 签署证据编号或证据链接（必须可追溯）

说明：

- 若以上任一必填项缺失，维护者可拒绝受理或要求补充后再审核。
- 审核通过后，维护者再填写审核相关字段并同步白名单。

## 提交流程（申请人）

1. 在本表新增一行，完整填写“提起审核用户必填内容”。
2. 在 PR 评论中附本次登记行说明与证据链接。
3. 等待维护者审核并同步 `.github/cla-signed-users.txt`。

## 字段说明

- 贡献者标识：GitHub/GitLab 用户名（唯一键）
- CLA 版本：对应 `CLA.md` 的版本或日期
- 签署日期时间（UTC+8）：建议 `YYYY-MM-DD HH:mm:ss`
- 签署方式：邮件 / PR 评论 / 表单 / 线下扫描件
- 签署证据编号或证据链接：邮件编号、PR 评论链接、附件路径等
- 审核状态：待审核 / 已通过 / 已拒绝 / 已撤销
- 审核人：维护者用户名
- 审核时间（UTC+8）：建议 `YYYY-MM-DD HH:mm:ss`
- 白名单同步状态：未同步 / 已同步 / 不适用
- 白名单同步时间（UTC+8）：建议 `YYYY-MM-DD HH:mm:ss`
- 备注：异常说明、补充说明
